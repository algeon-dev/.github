# .github

Organization profile and default community health files for
[algeon-dev](https://github.com/algeon-dev).

- `profile/README.md` is shown on the organization page.
- `SUPPORT.md` applies to every repository in the organization that has no
  `SUPPORT.md` of its own.

The main project lives in [algeon](https://github.com/algeon-dev/algeon),
which keeps its own `CONTRIBUTING.md`, `SECURITY.md` and
`CODE_OF_CONDUCT.md`.
