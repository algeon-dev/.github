# Support

Questions and bug reports for every repository in this organization, including
the cuDF, cuGraph and cuVS forks, go to the
[algeon issue tracker](https://github.com/algeon-dev/algeon/issues).
[CONTRIBUTING.md](https://github.com/algeon-dev/algeon/blob/main/CONTRIBUTING.md#proposing-a-change)
describes what a bug report should contain.

Security problems go through
[SECURITY.md](https://github.com/algeon-dev/algeon/blob/main/SECURITY.md),
not a public issue.

Bugs in upstream cuDF, cuGraph, cuVS, cuML, DataFusion or Arrow go to those
projects, unless an Algeon patch introduced them.
